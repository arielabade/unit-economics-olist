# Data

This directory is populated by the pipeline and is intentionally not committed.

```
data/raw/        Olist CSVs, downloaded by `python -m unit_economics.ingest`
data/processed/  Parquet outputs written by `python -m unit_economics.pipeline`
```

## Source

The Olist Brazilian E-Commerce dataset, originally published on
[Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce). This project reads a public
[Hugging Face mirror](https://huggingface.co/datasets/aviahYadler/Olist_Ecommerce_Dataset) of the
same files so that the analysis is reproducible without Kaggle credentials.

`ingest.verify()` asserts every file's row count against the published figures, so a truncated or
substituted mirror fails the run instead of quietly changing the results.

## Simulated fields

Acquisition channel and media spend do not exist in the Olist dataset. They are generated by
`src/unit_economics/channels.py` and are **simulated**. Channel-level CAC results demonstrate the
measurement framework; they are not statements about Olist's real marketing performance.
